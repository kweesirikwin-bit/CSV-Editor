ENCODING BYTE PATTERNS:
----------------------
UTF-8 BOM: EF BB BF
UTF-16 LE BOM: FF FE
UTF-16 BE BOM: FE FF

Thai UTF-8: E0 B8 xx or E0 B9 xx
Thai Windows-874: A1-DA, DF-FB

Thai character examples:
ท = B7 (Win-874) = E0 B8 97 (UTF-8) = U+0E17 (Unicode)
ม = C1 (Win-874) = E0 B8 A1 (UTF-8) = U+0E21 (Unicode)
ไ = E4 (Win-874) = E0 B9 84 (UTF-8) = U+0E44 (Unicode)

========================================
QUICK TROUBLESHOOTING:
========================================

Problem: Thai displays as ??????
→ Open file, check detection message
→ Should say "Windows-874" not "UTF-8"
→ If wrong, check actual file encoding

Problem: Can't type Thai
→ Verify edit control uses CreateWindowExW
→ Check SetWindowTextW / GetWindowTextW
→ Ensure CCM_SETUNICODEFORMAT sent

Problem: Encoding detection wrong
→ Check Thai byte patterns in file
→ E0 B8 xx = UTF-8
→ A1-FB range = Windows-874

Problem: Save corrupts Thai
→ Use correct save button
→ UTF-8 for modern systems
→ ANSI for legacy systems

Problem: Build fails
→ Check w64devkit installed
→ Verify library flags: -lcomctl32 -lcomdlg32 -lgdi32
→ Use -static flag for portability
